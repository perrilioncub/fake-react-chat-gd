# Fake React Chat (Geode mod)

AI-driven fake Twitch-style chat for Geometry Dash 2.2081 + Geode.

## Get the mod
1. Open the **Actions** tab of this repo, click the latest green run.
2. Download the **fake-react-chat** artifact (a zip) and unzip it.
3. Put the `.geode` file in your GD `geode/mods` folder and restart GD.
4. Geode menu -> Fake React Chat -> settings -> paste your Claude API key.
